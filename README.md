# 食事ログ

毎食の写真と食べたものを記録して、1日分を1枚の画像にまとめるスマホ向けWebアプリです。

## ファイル
- `index.html` … アプリ本体（HTML/CSS/JS、1ファイル完結）
- `sw.js` … オフラインで使うための部品（Service Worker）
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` … ホーム画面に追加するための設定とアイコン

## GitHub Pagesで公開する手順
1. GitHubで新しいリポジトリを作る（例: `meal-log`）。
2. このフォルダの中身（6ファイル）をすべてアップロードする。
3. リポジトリの **Settings → Pages** を開く。
4. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして保存する。
5. 数分後、`https://（ユーザー名）.github.io/（リポジトリ名）/` で開ける。

## 使う人への案内（ホーム画面に追加）
- iPhone: Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android: Chromeで開く → メニュー → 「ホーム画面に追加」または「アプリをインストール」
- 以後はホーム画面のアイコンから開く。LINEやチャットワーク内で開くと別の保存領域になり、記録が見えなくなることがある。

## データについて
- 記録は、使う人のスマホのブラウザ（IndexedDB）にだけ保存される。作者や他の人には見えない。GitHubにも送られない。
- 容量は、スマホの空き容量しだい（以前の約5MBよりずっと大きい）。
- 以前のバージョン（localStorage）で記録がある場合は、初めて開いたときに自動でIndexedDBへ移す。元のデータは消さずに残る。
- ブラウザのデータを消す、機種変更をすると記録は消える。引き継ぐ仕組み（書き出し・読み込み）はまだない。

## オフライン
- 一度インターネットにつないで開くと、アプリがスマホに保存され、電波がなくても開ける（撮影、記録、画像の保存もできる）。
- フォント（Zen Maru Gothic）は、一度つないだときに保存される。それまで・保存されていないときは、スマホ標準のフォントで表示される。
- 更新したとき: 電波があれば、開くたびに最新の `index.html` を取りに行く。電波がなければ、保存済みのものを使う。
- アイコンなど `index.html` 以外のファイルを変えたときは、`sw.js` の `CACHE = 'meal-log-v3'` を `v4` のように1つ上げると、みんなのスマホで入れ替わる。

## 更新するとき（記録を残すために）
- 記録は、アプリのURLと開き方ごとに、スマホの中に保存されている。更新は、**同じリポジトリのファイルを上書き**して行う（新しいリポジトリを作らない）。URLが変わると、これまでの記録は見えなくなる。
- 更新しても、これまでの記録はそのまま残る。古い形式の記録は、初めて開いたときに自動で新しい保存先へ移る（元のデータは消さずに残る）。
- **ホーム画面のアイコンは、消さない。** iPhoneでは、アイコンを消すと、そのアプリの記録も一緒に消える。新しいアイコンにしたいだけの場合は、古いアイコンのままで使い続けてよい（新しく使い始める人は、新しいアイコンになる）。
- ブラウザの「閲覧データ（サイトデータ）を消去」はしない。記録が消える。

## 保存の仕組み（Claude版との違い）
- 「画像を保存」は、共有メニュー（Web Share）が使える端末ではそこから「画像を保存」を選べる。使えない場合は通常のダウンロードになる。
- 保存できないときは、画像を長押しして「写真に保存」。
